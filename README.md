# Ahmed Elsayed — Portfolio

A responsive static portfolio website generated from the supplied CV.

## Preview locally
Open `index.html` in a browser. Keep the `assets` folder beside it so the CV buttons work.

## Publish free with GitHub Pages
1. Create or sign in to a GitHub account.
2. Create a public repository named exactly `YOUR-USERNAME.github.io`.
3. Upload `index.html` and the `assets` folder to the repository root.
4. Wait for GitHub Pages to publish the site.
5. Your site address will be `https://YOUR-USERNAME.github.io/`.

The website is static HTML/CSS/JS and needs no build process.

## Before publishing
Review the contact details and the CV file. The portfolio content follows the supplied CV; add GitHub or other project/demo links only when you have verified public URLs.
